佣金状态机

资金流转的唯一真相
created 用户进入问卷，锁配额 → pending 提交答卷，写入冻结（用户可见"待结算"） → reviewing 风控命中，转人工复核 → approved 题源 Postback 验签通过 + 风控通过 → available 冻结期结束，计入可用余额 → paid 提现成功（微信 / 支付宝代付） 异常分支 → rejected 复核驳回 / 题源 screenout，佣金回滚，配额返还 → reversed 题源事后冲正（30 天内可发起）

transaction_id 唯一索引，重复回调返回 200
非 200 时按 1m / 5m / 30m 退避，最多 5 次

打款纪律

钱出去了就回不来，这几条是硬约束
用户提交提现只扣可用余额、落 pending；真正付款由财务在此确认，状态才变 paid。
审核员能看提现单但不能打款（无 withdrawal:pay），财务能打款但不能改佣金（无 commission:review）。
标记失败会把金额退回用户可用余额并记一条流水，不允许「扣了钱又显示失败」。
每笔打款写审计：操作人、金额、渠道、时间，事后可查。
